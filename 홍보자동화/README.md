# 홍보자동화 (Auto Generate App)

매장 사진을 인스타그램용 정사각형 이미지로 자동 변환하고, 가게 정보를 바탕으로
채널별(인스타그램 / 네이버 블로그 / 카카오톡) 홍보 문구까지 한 번에 만들어주는
자동화 도구입니다.

## 주요 기능

- `자료` 폴더의 모든 jpg/png 사진을 1080x1080 정사각형으로 자동 변환 (중앙 기준 크롭, 비율 왜곡 없음)
- 사진 오른쪽 아래에 로고를 자동 삽입 (흰 배경 처리로 가시성 확보, 로고 파일 없으면 자동 생략)
- `가게 정보.txt`를 읽어 감성형 / 정보형 / 이벤트형 3가지 톤의 홍보 문구 자동 생성
- 인스타그램 / 네이버 블로그 / 카카오톡 단골 공지용으로 채널별 문구 분리 생성
- 사장님의 실제 SNS 글(`내 말투.txt`)을 분석해 반영한 담백한 합쇼체 말투
- 인스타그램용 해시태그(지역 + 업종 + 메뉴 조합) 자동 생성
- 원본 사진은 전혀 수정하지 않고 `완성` 폴더에만 결과물 저장

## 실행 방법

바탕화면의 로고 아이콘("홍보물만들기")을 더블클릭하면 됩니다.

또는 아래 명령어를 직접 실행합니다.

```
"C:\Users\pc\AppData\Local\Programs\Python\Python312\python.exe" "promo_maker.py"
```

자세한 사용법은 [사용설명서.txt](./사용설명서.txt)를 참고하세요.

## 폴더 구조

```
홍보자동화/
├── promo_maker.py       # 메인 스크립트 (사진 변환 + 문구 생성)
├── run.bat              # 더블클릭 실행용 배치 파일
├── 로고.ico             # 바탕화면 아이콘용 로고
├── 사용설명서.txt        # 비개발자용 사용 설명서
├── CLAUDE.md            # 작업 규칙
├── 자료/                # 원본 사진, 가게 정보.txt, 내 말투.txt, 로고 원본
└── 완성/                # 변환된 사진과 홍보문구.txt (결과물)
```

## 필요 환경

- Python 3.12
- Pillow (이미지 처리 라이브러리)
